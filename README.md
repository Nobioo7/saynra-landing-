# Synra Landing Page

Synra — A memory your AI keeps. Local-first persistent context for Cursor, Claude, and ChatGPT.

## Overview
- **Local-first context**: Dual-write storage with Markdown vault.
- **Visual knowledge map**: 3D interactive Canvas2D anatomical brain graph.
- **Integrations**: MCP Server for Cursor & Claude, Chrome Extension for web AI chats.

## Deployment
This project is static HTML/CSS/JS and can be deployed directly on [Vercel](https://vercel.com) or GitHub Pages.

### Run Locally
Simply open `index.html` in any modern web browser or serve via:
```bash
npx serve .
```
